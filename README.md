# HCMUT Grade Tools

Download all the files.
Double-click the `.bat` files.

## GPA analysis (local only)

1. `get_all_grades_from_all_sem(run_this_1st).bat` - downloads grades → `all_grades.json`
2. `analyze_grades(run_this_2nd).bat` - shows GPA, stats and some analysis

## Get early grade for 1 semester

`get_grade_early_for_1_sem.bat` - log in, pick a semester, see grades not public yet on screen
